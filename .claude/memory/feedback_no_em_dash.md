Never use em dash (U+2014) anywhere. Use commas, parens, or " - " instead.

**Why:** Strong LLM-writing tell. Universal rule across all repos.

**How to apply:** Applies to all text output - code comments, commit messages, docs, chat responses, JSX text nodes, ARIA labels.
